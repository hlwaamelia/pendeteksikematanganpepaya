# PapayaCheck

Website untuk memperkirakan kematangan buah pepaya dari foto.
Analisis dilakukan di browser berdasarkan warna kulit buah; foto tidak dikirim ke server.

## Cara pakai
Buka halaman website, unggah foto pepaya (latar polos, cahaya terang), lalu lihat hasilnya.

## Catatan
Ini deteksi berbasis aturan warna, bukan model AI terlatih. Hasil berupa perkiraan.
